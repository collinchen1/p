GPU Resilience Analysis using Statistical Modeling & LLMs

Overview

This project analyzes two years of GPU failure logs from a production HPC cluster (400 NVIDIA A100 GPUs across 100 nodes; 100K+ XID events) to understand failure behavior, reliability, and opportunities for improved diagnosis. The work combines large-scale log analysis, statistical modeling, and LLM-assisted interpretation in Python.

The study transforms raw nested logs into structured data, characterizes dominant XID errors, models interarrival and hazard behavior, and explores hybrid statistical + LLM approaches for more interpretable resilience analysis.

Data Pipelines & Failure Characterization

Built data pipelines with Pandas, NumPy, and SciPy to parse and transform nested log data (pickle to DataFrame), enabling structured coverage of raw logs and efficient time-series querying. Computed statistical metrics (mean, variance, percentiles) and estimated probabilities of critical XID events, identifying dominant error types contributing to a large share of failures.

Implemented log deduplication and coalescing algorithms to reduce dataset size while preserving true failure events, and visualized failure patterns with Matplotlib/Seaborn, including log-scale frequency plots and interarrival histograms revealing heavy-tailed and bursty behavior.

Reliability & Statistical Modeling

Modeled interarrival times of GPU failures and evaluated Exponential, Normal, Uniform, and Lognormal fits using Kolmogorov–Smirnov tests (p-value threshold 0.05). Identified Poisson-like failure behavior, estimated system failure rate (λ), and derived MTBF estimates for full-cluster workloads.

Performed reliability analysis including MTBF, hazard rate, and Nelson–Aalen cumulative hazard estimation, validating consistency between empirical observations and theoretical models.

Clustering, Propagation & Probabilistic Inference

Conducted temporal clustering of XID events using a 600-second window, showing that a majority of failures occur in multi-event clusters indicative of correlated error bursts. Built XID propagation models (transition probability matrices) to identify high-probability error sequences for failure diagnosis.

Implemented ML and MAP hypothesis testing for interpretable probabilistic classification of XID-induced failures and designed a Naive Bayes model for multi-event clusters to enable scalable inference over unordered XID sets.

LLM Integration

Integrated a 7B-parameter LLM (Qwen2.5-7B) for log analysis and evaluated its ability to classify and explain XIDs, identifying limitations in domain-specific accuracy without context. Improved response quality and reduced hallucination by augmenting prompts with structured XID documentation through retrieval-based context injection.

The project explored hybrid statistical + LLM approaches, demonstrating how probabilistic modeling combined with contextual LLM reasoning can improve the interpretability of system failures.
