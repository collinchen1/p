SLC-3 in SystemVerilog

Overview

This project implements an SLC-3 (a simplified LC-3-style) processor in SystemVerilog. The processor integrates a multi-cycle datapath, control FSM, memory subsystem, and memory-mapped I/O into a working CPU design for simulation and FPGA-oriented synthesis.

The top-level design brings together the CPU core, synchronized inputs, memory, and debug displays so programs can be loaded, executed, and observed through LEDs and seven-segment outputs.

Datapath & Control

The CPU includes core architectural components such as the program counter (PC), instruction register (IR), memory address register (MAR), memory data register (MDR), register file, ALU, and condition-code logic (NZP with branch enable).

A finite-state machine in the control unit sequences instruction fetch, decode, and execute phases, generating control signals for register loads, bus gating, ALU operations, address calculation, branching, and memory accesses.

Instruction & Execution Support

The SystemVerilog implementation supports key SLC-3/LC-3 operations reflected in the design, including arithmetic and logic instructions (ADD, AND, NOT), memory access instructions (LDR, STR), control-flow instructions (BR, JMP, JSR), and related instruction decode/state transitions.

Instruction and memory initialization utilities in the project provide encoded test/program contents used to exercise processor behavior during development and verification.

Memory & I/O Integration

The memory subsystem handles synchronous read/write behavior with multi-cycle wait states and supports both simulation memory and synthesis-oriented RAM initialization/integration. A CPU-to-I/O bridge maps memory-mapped interactions, including reading switch inputs and writing hexadecimal display output at address 0xFFFF.

Debug visibility is built into the design: instruction/state-related values are routed to LEDs and hex displays (including debug output paths from the CPU), helping validate execution on hardware and in simulation.

Design Files

Key modules in the project include the SLC-3/core integration, CPU datapath and control logic, register/ALU/NZP components, memory and I/O interfaces, synchronizers/debouncers, and hex display drivers. Together, these SystemVerilog files form a complete processor system used for the lab implementation and report.
